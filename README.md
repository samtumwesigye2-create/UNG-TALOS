# UNG-TALOS

**Threat Analysis, Logging, Observation & Security**

UNG-TALOS is the standalone defensive security monitoring system for the UNG ecosystem. Phase 1 is being reconstructed from the approved CERBERUS transfer source under the new TALOS name. It monitors configured systems through read-only integrations, raises security incidents from detection rules, preserves tamper-evident incident history, and keeps containment human-approved.
